# Reflect

1. Use the current conversation as the primary evidence. If exact prior turns
   are missing, use `tracedecay:managing-session-context`; do not scan Cursor
   transcript directories.
2. Run three independent read-only lenses when delegation is available and
   requested by this skill: judgment, tooling, and divergent/generalization.
3. Require every proposed lesson to cite a correction, repeated dead end,
   successful generalizable sequence, or recurring preference.
4. Classify proposals as Accepted, Rejected, or Backlog. Route enforceable
   rules to code, lint, metadata, or scripts instead of prose.
5. Present the classification and wait for explicit approval before changing a
   durable skill or memory. The user's invocation authorizes analysis, not
   every proposed persistent edit.
6. Apply approved skill changes through Codex `skill-creator`, validate them,
   and run focused evals when behavior is objectively testable.

Return applied edits, created skills, structural backlog, and rejected lessons
with one-line reasons. Never store secrets or transient task progress.
